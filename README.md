# Сөз әлемі / Word World

Балаларға қазақша және ағылшынша сөздерді сурет пен дыбыс арқылы үйрететін интерактивті веб-қосымша.

## Мүмкіндіктер

- 16 авторлық иллюстрация
- Қазақша және ағылшынша интерфейс
- Суретті басқанда сөзді дауыстап айту
- Жануарлар, заттар, тағамдар және қоршаған әлем бөлімдері
- «Үйрену» және «Тап» ойын режимдері
- Дұрыс жауаптар үшін жұлдыз жинау
- Телефон мен компьютерге бейімделген дизайн

## Іске қосу

`index.html` файлын заманауи браузерде ашыңыз. Дыбыстау браузердегі Web Speech API арқылы жұмыс істейді. Қазақ тіліндегі дауыстың сапасы құрылғыда орнатылған дауыстарға байланысты болуы мүмкін.

## Технологиялар

HTML, CSS, JavaScript және Web Speech API.
